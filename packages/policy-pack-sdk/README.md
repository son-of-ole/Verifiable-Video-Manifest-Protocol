# @vvmp/policy-pack-sdk

Policy-pack SDK for VVMP.

Use this package to define domain-specific checks and execute them against manifests, script segments, sources, prompts, tools, and assets.

```sh
npm install @vvmp/policy-pack-sdk
```

```ts
import { definePolicyPack, runPolicyPack } from "@vvmp/policy-pack-sdk";
```

See the root repository package integration guide for the full package map.
