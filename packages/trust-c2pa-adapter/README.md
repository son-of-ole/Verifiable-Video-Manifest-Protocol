# @vvmp/trust-c2pa-adapter

C2PA adapter helpers for VVMP.

Use this package for prototype sidecars, C2PA export/read flows, local trust profiles, trust-program configuration, and trustmark helpers.

```sh
npm install @vvmp/trust-c2pa-adapter
```

```ts
import { exportC2paManifest, readC2paManifest } from "@vvmp/trust-c2pa-adapter";
```

See the root repository package integration guide for the full package map.
